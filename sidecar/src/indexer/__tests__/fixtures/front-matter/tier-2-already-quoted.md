# Quoted Agent

This fixture has a description already wrapped in double quotes. The Tier 2
pre-processor must detect that the value starts and ends with " and leave it
alone — no double-escaping. The already-quoted check is the first guard in the
BC1 algorithm before DANGEROUS_CHARS_RE is tested.
